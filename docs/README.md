# 📚 Project Documentation

This folder contains detailed documentation for the project setup, development workflow, and automation scripts.

## Documents

- [bootstrap.md](bootstrap.md)  
  Explains the purpose and usage of the `bootstrap.sh` script, which automates the initial setup of the development environment.

## Purpose

The `/docs` folder centralizes all documentation, avoiding clutter in the main `README.md` of the repository.  
While the top-level `README.md` gives a quick overview of the project, this folder dives deeper into:

- Development environment setup
- CI/CD configuration
- Coding standards and guidelines
- Automation scripts (like `bootstrap.sh`)
- Any future architecture/design notes

## Contributing

- Keep each document **focused** (one topic per file).
- Use clear Markdown formatting (titles, lists, code blocks).
- Link between documents whenever possible.
